# SYSTEM MONITORING DASHBOARD

A modern system monitoring dashboard built with **Next.js + TypeScript**.  
This project simulates a real infrastructure control panel with live system logs, metrics, and status monitoring UI.

---

## Overview

This project is a frontend-only concept dashboard designed to simulate:

- System metrics monitoring
- Live log streaming
- Server status overview
- Clean SaaS-style UI

It focuses on:
- UI/UX structure
- component architecture
- modern frontend design patterns

---

## Features

- System metrics dashboard (CPU, uptime, sessions, error rate)
- Live updating system logs (simulated real-time data)
- System status indicator
- Dark SaaS-style UI design
- Smooth UI interactions
- Modular component architecture

---

## Tech Stack

- Next.js (App Router)
- TypeScript
- React
- CSS Modules
- Framer Motion
